# Technical Enablement

Short guides that help a non-developer use a technical tool safely on their first day.

Courses:

- [Git for New Testers](git-workflow-guide/): Four 30-minute sessions on save points, branches, pull requests and conflicts, with a quiz and an eight-command cheat sheet.
- [Jira for New Testers](jira-workflow-guide/): Three 30-minute sessions on writing a bug ticket others can reproduce and knowing whose turn each status is, with a quiz and a status table.
