# Quiz

Eight questions, given after session 4. One point each. Six or more means you are ready to work on a real project. Fewer than six means going back over the sessions in the [full version](full/git-workflow-guide-full.md#the-four-sessions) before you do. The course page has the same quiz one question at a time, with the right answer and a reason after each pick.

## Questions

1. What does a commit do?
2. Why work on a branch instead of main?
3. Which command starts a new branch and moves you onto it?
4. What does `git add` do?
5. What does `git push` do?
6. What is a pull request?
7. Git says CONFLICT in a file. What happened?
8. Which file should never be committed?
