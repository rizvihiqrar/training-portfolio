After ten one-hour days, a tester who has never written code can open a project in VS Code, ask an AI helper for help, and write and run a simple automated test of a website. Two of the days are hands-on, with no video, because the goal is to do, not only watch.

## What Is in Each Course

- **A course page:** who it is for, the goal, the outline, the design decisions, how learning was checked, and what I would improve
- **A one-page lesson plan:** timings in minutes, what the trainer does, what the learners do, and how each step is checked
- **A quiz:** ten questions, with the answers kept by the trainer
- **A scoring guide:** five criteria scored from 1 to 4, with a next step for every total
- **A feedback form:** what learners thought, and how the answers change the next run
- **Handouts:** Word files you can download one at a time, or all together in a ZIP

## How I Check That People Learned

- **During the lesson:** a quick check at the end of every step, so someone who is lost is found in minutes
- **Halfway:** a midpoint check, so anyone behind gets help before the second half starts
- **At the end:** a quiz and a practical round scored with the scoring guide
- **Later:** one question a month on, "have you used this since?"
