# How It Works

How the courses are built and how I check that people learned. Every company, system and person here is made up, so nothing comes from an employer.

## What Is in a Course Pack

| Item | What it is for |
|---|---|
| Course page | Who it is for, the goal, the outline, how learning was checked, and what I would improve |
| Lesson plan | One page: timings, activities, what to prepare, what to cut if time runs short |
| Quiz | Ten questions to check understanding |
| Scoring guide | How a practical round is scored, so two trainers mark the same way |
| Feedback form | What learners thought, and what changed because of it |
| Handouts | Word files learners keep |

## How I Check That People Learned

- **During the lesson:** A quick check at each step, so anyone lost is found in minutes, not weeks.
- **Halfway:** A midpoint check, before the second half starts.
- **At the end:** A quiz and a practical round, scored with the scoring guide.
- **A month later:** One question, "have you used this since?" A good score shows people understood, not that their work changed.
- **After each run:** The feedback and the common mistakes become the first change for next time.
