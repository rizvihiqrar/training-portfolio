# Lesson Plan: Day 5, Practice with VS Code and Copilot

**Course:** QA automation onboarding  **Session:** Day 5, the midpoint check (the Week 1 benchmark)

**By the end, learners can:**
- Find their way around VS Code and open the integrated terminal.
- Ask Copilot for code in everyday words and say what it did.
- Tell a good suggestion from one that needs checking.

| Length | Step | Objective | Goals | Check |
|---|---|---|---|---|
| 5 min | Open | Say today is about doing, not watching | Name one thing from Days 1 to 4 that helped or confused | One sentence each |
| 5 min | Setup check | Make sure VS Code, Copilot and the terminal open | Open an empty folder and the terminal (Ctrl+`) | Everyone has a terminal |
| 10 min | Prompt 1 | Show inline chat (Ctrl+I) | Ask for a password-check function | Ghost text accepted (Tab) or dismissed (Esc) |
| 10 min | Prompt 2 | Ask "what does that line do?" | Ask for a function that totals a list of prices | Explain one line in their own words |
| 10 min | Prompt 3 | Remind them to review before trusting | Paste short code and ask for an everyday-words explanation | Compare the explanation with the code |
| 15 min | Review | Ask each learner to find one thing the AI got wrong | Run each function with a few inputs | One problem found per learner |
| 5 min | Close | Recap: AI suggests, I review, I run it | Write down one thing to try tomorrow | Terminal opened, snippet reviewed |

**Total:** 60 min.

**Prepare:** Each learner has VS Code and Copilot signed in, and Node.js installed (needed from Day 7). Have the three prompts on a slide or a printed card.

**If a learner has no Copilot:** Pair them with someone who does for Prompts 1 to 3 and have them review and run the code, or let them use any free AI chat assistant in a browser and paste its code into VS Code. The Week 1 benchmark is the same either way: a snippet from a prompt written in everyday words, reviewed and run.

**If time runs short:** Drop Prompt 2. Never drop the review step: it is the habit the whole programme depends on.

**Afterwards:** Note who did not reach the benchmark and check in with them before Day 6. Record the common mistakes (usually "accepted without reading") and add them to next run's opening.
